# Screenshots

The screenshots in the README and the AppStream metadata are generated by the app's own offscreen
renderer (needs a GPU adapter or a software Vulkan driver such as lavapipe):

```sh
cargo run -p khata-ui-egui --example ui_shot
```

Save the results in `docs/images/` as `hero.png`, `backstage.png`, `dark.png` and `design.png`. The old
WordCraft-branded screenshots were removed in the Khata rebrand.
